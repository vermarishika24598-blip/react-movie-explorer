# 🎬 IMDb Movie Explorer

A responsive, feature-rich web application that allows users to explore movies, search for their favorite titles, and maintain a personal watchlist and favorites list.

## 🚀 Live Demo
[Check out the project here](https://react-movie-explorer-w35l.vercel.app/)

## 🛠 Tech Stack
* **Frontend:** React.js, Tailwind CSS
* **API:** TMDB (The Movie Database) API
* **Deployment:** Vercel

## ✨ Key Features
* **Real-time Search:** Search movies on the fly.
* **Movie Discovery:** Explore Popular, Top-Rated, and Upcoming movies.
* **Personalized Lists:** Save movies to your **Watchlist** and **Favorites**.
* **Responsive UI:** Fully optimized for mobile and desktop.

## 📦 How to run locally
1. **Clone the repo:** `git clone <your-repo-url>`
2. **Install:** `npm install`
3. **Start:** `npm start`
